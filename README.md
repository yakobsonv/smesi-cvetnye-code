# Цветные кладочные смеси — сайт дилера (ООО «Кирпичный трест»)

Новый сайт о цветных кладочных растворах для облицовочного кирпича: Perel (SL, VL, NL, затирка RL)
и Основит (Брикформ МС11, МС11/1, расшивка Бриксэйв ХС30). Собран 09.10.2026 по плану страниц,
на который Влад дал «го» (vault: «Николай (стройматериалы)/Цветные смеси — разведка и план страниц (09.10.2026)»).
Механика (компоненты, формы, правовые страницы) взята из `~/recke-code`.

- Стек: Astro 6, статическая сборка, без UI-фреймворков. `npm run build`, `npm run check`.
- Превью: https://smesi-cvetnye-code.vercel.app — отдельный проект Vercel. Выкладка: `vercel deploy --prod --yes` из корня.
- Домена нет: noindex на всех страницах, `X-Robots-Tag` в `vercel.json`, `Disallow: /` в `robots.txt`, canonical на превью.
- Приём заявок НЕ подключён (слово Влада): у проекта нет переменных окружения, `api/lead.js` отвечает 503, форма показывает телефон.
- Цен на сайте нет: цены производителей не ставим, дилерские — только по слову Влада.

## Данные (src/data)
- `catalog.ts` — ассортимент дилера (tk-sm.ru, 09.10.2026): серии, палитры с кодами, позиции.
- `series-facts.ts` — характеристики серий дословно с сайтов производителей, у каждого значения URL источника.
- `swatches.ts` — приближённые оттенки образцов (замер по картинкам-палитрам производителей).
- `kladka.ts` + `public/assets/kladka/` — визуализации кладки из материалов клиента (Яндекс.Диск, «Текстуры (кладки)»), подпись шва — по видимому цвету.
- `legal.ts` — документы клиента (Положение, Согласие), подставляется только адрес сайта.
