## Что это
Сайт дилера ООО «Кирпичный трест» (Москва и МО) о **цветных кладочных смесях** для облицовочного кирпича — только цветные смеси (слово Влада 11.10). Бренды: **Perel** (SL, VL, NL, затирка RL) и **Основит** (Брикформ МС11, МС11/1, расшивка Бриксэйв ХС30) — 120 позиций по ассортименту дилера tk-sm.ru.

- **Превью:** https://smesi-cvetnye-code.vercel.app — закрыто от поиска (noindex, `X-Robots-Tag`, `robots.txt Disallow`), canonical на превью. Домена пока нет.
- ⚠️ Из России превью на *.vercel.app открывается через раз (11.10: 1 из 8 точек) — это блокировка адресов Vercel, не поломка.

Секретов в репозитории нет и класть нельзя. Паша (GitHub `Paul1l`) приглашён с правом записи — принять приглашение на GitHub.
- **Проект Vercel:** `smesi-cvetnye-code` в аккаунте Влада, подключён к репозиторию: **пуш в `main` сам выкладывает сайт** (проверено 14.10: коммит `e3079ff` → READY за ~20 с). Аккаунт Vercel Паше не нужен.
- **Задача на доске:** №47 «Цветные смеси: принять сайт и сделать первую правку» (срок 16.10).

## Как работать с кодом
```
git clone https://github.com/yakobsonv/smesi-cvetnye-code.git
npm install
npm run dev          # локально
npm run build        # сборка, должна пройти без ошибок
npm run check        # проверка типов — 0 ошибок
git push origin main # выкладка: Vercel собирает и выкладывает сам
```
Ветки, кроме `main`, дают превью-деплои Vercel под авторизацией — проверять на `main` после выкладки или локально.

## Правила (обязательно)
1. **Факты — только из `src/data/`** и сайтов производителей (td-perel.ru, osnovit.ru), со ссылкой на источник. Ничего не досочинять. Тексты tk-sm.ru и сайтов кирпича клиента не копировать.
2. **Цен нет** — кнопка «Узнать цену». Ставить цены только по слову Влада.
3. **Дизайн** — язык «палитра шва» (11.10, после замечания Влада «шаблон не тот же, ещё и везде кирпич»): антиква Cormorant Garamond + Golos Text, бумага и тушь, тонкие линии вместо карточек, без скруглений и теней, цвет дают только плашки раствора. **Кирпича нет нигде, кроме `/podbor-shva/`.**
4. **Приём заявок не подключён** (слово Влада): `api/lead.js` без переменных окружения отвечает 503, форма показывает телефон офиса. Метрику до домена не ставить.
5. Служебных фраз для нас на страницах быть не должно.
