## Что это

Сайт ООО «Кирпичный трест» (Москва и МО) о **цветных кладочных смесях** для облицовочного кирпича — только цветные
смеси (слово Влада 11.10). Бренды: **Perel** (SL, VL, NL, затирка RL) и **Основит** (Брикформ МС11, МС11/1, расшивка
Бриксэйв ХС30) — 120 позиций по ассортименту магазина Николая tk-sm.ru. 13 страниц.
Превью: **https://smesi-cvetnye-code.vercel.app** (закрыто от поиска). Домена пока нет.

Документы проекта (копии на 14.10; актуальная передача — в Обсидиане Влада, читается через API доски, см. ниже):
- `docs/01-передача-14.10.md` — что за сайт, где что лежит, правила, как проверять, 7 открытых вопросов;
- `docs/02-разведка-и-план-страниц-09.10.md` — разведка ассортимента и план страниц (волны 1 и 2);
- `.impeccable.md` — направление дизайна.

## Правила (нарушение = работа не сделана)

1. **Факты — только из `src/data/`** и сайтов производителей (td-perel.ru, osnovit.ru), у каждого значения ссылка
   на источник. Ничего не досочинять. Тексты tk-sm.ru и сайтов кирпича клиента не копировать.
2. **Цен нет** — кнопка «Узнать цену». Ставить цены только по слову Влада.
3. **Дизайн — язык «палитра шва»** (11.10, после замечания Влада «шаблон не тот же, ещё и везде кирпич»):
   Cormorant Garamond + Golos Text, бумага и тушь, тонкие линии вместо карточек, без скруглений и теней, цвет дают
   только плашки раствора. **Кирпича нет нигде, кроме `/podbor-shva/`.**
4. **Только цветные смеси.** Сухие смеси — соседний сайт «Сухие смеси», сюда их не ставим.
5. **Приём заявок не подключён** (слово Влада): `api/lead.js` без переменных окружения отвечает 503, форма показывает
   телефон офиса. Переменные окружения не заводить. Метрику до домена не ставить.
6. **Служебного на странице быть не должно** («уточнить», «по данным клиента», «TBD»). Всё, что лежит в `src/data/**`,
   может оказаться на экране — проверять собранный HTML (`dist/`), а не исходник.
7. **Картинки производителей (мешки, палитры) — только после слова Влада** (открытый вопрос 4 в передаче).
   Каждый кадр смотреть глазами; маленький исходник не растягивать.
8. **Пока нет домена — noindex в трёх местах** (метатег, `X-Robots-Tag` в `vercel.json`, `public/robots.txt`).
9. **Живые сайты Николая на конструкторе mottor не трогать** (решение Влада 05.10) — только читать.
10. **Репозиторий открытый** — секретов (токены, пароли, ключи) не класть ни в код, ни в документы, ни в коммиты.
11. **Решения, которых нет в `docs/`, — спрашивать Влада**, не додумывать.

## Доступ, окружение, выкладка, откат

- **Приглашение GitHub** (аккаунт `Paul1l`, право записи): https://github.com/yakobsonv/smesi-cvetnye-code/invitations —
  действует 7 дней; истекло — написать Владу.
- **Клонирование:** `git clone https://github.com/yakobsonv/smesi-cvetnye-code.git`. Для пуша нужна авторизация GitHub:
  `gh auth login` или SSH-ключ в настройках GitHub. Перед работой — `git pull` (в репозиторий может писать и Влад).
- **Окружение:** Node ≥ 22.19 (Astro 6 требует ≥ 22.12, пакет undici — ≥ 22.19). Зависимости — `npm ci`
  (не `npm install`: он переписывает `package-lock.json`). `npm audit fix --force` и обновление пакетов — только по слову Влада.
  Python 3.10+ для скриптов: `python3 -m venv .venv && . .venv/bin/activate && pip install playwright pillow && python -m playwright install chromium`
  (`.venv/` в git не идёт).
- **Выкладка = `git push origin main`.** Это превью на *.vercel.app с noindex, а не боевой сайт клиента: правило базы
  знаний «Граница прода» (выкладка на живой сайт — только по слову Влада) относится к боевым сайтам Николая, а пуш
  в main по задаче разрешён. Перед пушем — сборка и проверка типов без ошибок.
- **После пуша** — статус Vercel у коммита на GitHub: зелёная галочка у коммита или
  `gh api repos/yakobsonv/smesi-cvetnye-code/commits/<sha>/status -q .state` → `success`. Затем рендер выложенной версии с `?v=<случайное>`.
  Красный статус или сайт сломан — `git revert <sha> && git push origin main` и сразу написать Владу (логи сборки у него).
  `git push --force` и `rebase` опубликованного `main` — нельзя.
- **Первый пуш — маленький** (например, строка в README): убедиться, что выкладка от твоего аккаунта проходит.
  Нет зелёной галочки за 2–3 минуты — написать Владу.
- Из России *.vercel.app открывается через раз (блокировка адресов Vercel, не поломка): повторить или проверить через
  VPN; не открылось совсем — проверить локально (`npm run build && npm run preview`) и прямо написать в отчёте, что

## Как работать

```bash
npm ci                 # зависимости строго по package-lock.json
npm run dev            # локально, http://localhost:4321
npm run build          # сборка без ошибок (13 страниц)
npm run check          # 0 ошибок
git push origin main   # = выкладка: Vercel собирает и выкладывает сам (~20 с)
python3 scripts/check_site.py https://smesi-cvetnye-code.vercel.app   # проверка выложенной версии (после build)
```

Ветки, кроме `main`, дают превью-деплои Vercel под авторизацией — проверять на `main` после выкладки или локально.

## «Готово» — только так

- Выложено и проверено на **выложенной** версии с `?v=<случайное>` на 1440, 768, 390 и 320 px.
- `python3 scripts/check_site.py https://smesi-cvetnye-code.vercel.app` (из корня, после `npm run build`) — все страницы
  × 4 ширины: код ответа, один h1, нет прокрутки вбок, нет ошибок в консоли, нет битых картинок; итог «с проблемами 0».
  На 14.10: 52 проверки, проблем 0.
- Скрипт — помощник, не единственная правда: глазами каждую затронутую секцию **плюс клики** (образец открывает окно
  «Узнать цену» с позицией, фильтры каталога, калькулятор) — их скрипт не проверяет.
- Браузер для скриптов — **только Playwright Chromium**, обычный Chrome скриптом не запускать.
- Локальный предпросмотр: перед съёмкой проверить по `<title>`, что порт отдаёт этот сайт.
- **Отчёт — на доске задач** (`yakobsonv.com/ru/cabinet/staff`, проект `kirpichtrest`): что сделано, ссылка на выложенную
  версию, как проверено.

## Грабли, уже наступленные

- Стили Astro не доходят до узлов, которые рисует скрипт (`innerHTML`) и до элементов дочернего компонента —
  стилизовать через `:global()` внутри родителя.
- Оттенки плашек (`src/data/swatches.ts`) — приближение по картинкам-палитрам производителей; рядом с образцами
  стоит оговорка о цветопередаче экрана — не убирать.
- Временная папка `/private/tmp` чистится — рабочие данные держать в репозитории.
