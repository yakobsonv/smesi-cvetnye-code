## Правила (нарушение = работа не сделана)

1. **Факты — только из `src/data/`** и сайтов производителей (td-perel.ru, osnovit.ru), у каждого значения ссылка
   на источник. Ничего не досочинять. Тексты tk-sm.ru и сайтов кирпича клиента не копировать.
2. **Цен нет** — кнопка «Узнать цену». Ставить цены только по слову Влада.
3. **Дизайн — язык «палитра шва»** (11.10, после замечания Влада «шаблон не тот же, ещё и везде кирпич»):
   Cormorant Garamond + Golos Text, бумага и тушь, тонкие линии вместо карточек, без скруглений и теней, цвет дают
   только плашки раствора. **Кирпича нет нигде, кроме `/podbor-shva/`.**
4. **Только цветные смеси.** Сухие смеси — соседний сайт «Сухие смеси», сюда их не ставим.
5. **Приём заявок не подключён** (слово Влада): `api/lead.js` без переменных окружения отвечает 503, форма показывает
   телефон офиса. Переменные окружения не заводить. Метрику до домена не ставить.
6. **Служебного на странице быть не должно** («уточнить», «по данным клиента», «TBD»). Всё, что лежит в `src/data/**`,
   может оказаться на экране — проверять собранный HTML (`dist/`), а не исходник.
7. **Картинки производителей (мешки, палитры) — только после слова Влада** (открытый вопрос 4 в передаче).
   Каждый кадр смотреть глазами; маленький исходник не растягивать.
8. **Пока нет домена — noindex в трёх местах** (метатег, `X-Robots-Tag` в `vercel.json`, `public/robots.txt`).
9. **Живые сайты Николая на конструкторе mottor не трогать** (решение Влада 05.10) — только читать.
10. **Репозиторий открытый** — секретов (токены, пароли, ключи) не класть ни в код, ни в документы, ни в коммиты.
11. **Решения, которых нет в `docs/`, — спрашивать Влада**, не додумывать.

## Как работать

```bash
npm install
npm run dev            # локально, http://localhost:4321
npm run build          # сборка без ошибок
npm run check          # 0 ошибок
git push origin main   # = выкладка: Vercel собирает и выкладывает сам (~20 с)
```

Ветки, кроме `main`, дают превью-деплои Vercel под авторизацией — проверять на `main` после выкладки или локально.

## «Готово» — только так

- Выложено и проверено своим рендером **выложенной** версии с `?v=<случайное>` на 1440, 390 и 320 px: прокрутки вбок
  нет, один h1, ошибок в консоли нет; глазами каждую затронутую секцию **плюс клики** (образец открывает окно
  «Узнать цену» с позицией, фильтры каталога, калькулятор).
- Скрипты проверки — **только Playwright (Chrome for Testing)**: `pip install playwright && python3 -m playwright install chromium`.
  Обычный Chrome скриптом не запускать (правило Влада 08.10).
- Локальный предпросмотр: перед съёмкой проверить по `<title>`, что порт отдаёт этот сайт.
- Из России *.vercel.app открывается через раз — это блокировка адресов Vercel, а не поломка сайта.
- **Отчёт — на доске задач** (`yakobsonv.com/ru/cabinet/staff`, проект `kirpichtrest`): что сделано, ссылка на выложенную
  версию, как проверено.

## Грабли, уже наступленные

- Стили Astro не доходят до узлов, которые рисует скрипт (`innerHTML`) и до элементов дочернего компонента —
  стилизовать через `:global()` внутри родителя.
- Оттенки плашек (`src/data/swatches.ts`) — приближение по картинкам-палитрам производителей; рядом с образцами
  стоит оговорка о цветопередаче экрана — не убирать.
- Временная папка `/private/tmp` чистится — рабочие данные держать в репозитории.
